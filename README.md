# 🏡 EstateHub – Real Estate Management Website

## 📌 Project Description
EstateHub is a web-based Real Estate Management System developed as part of the Web Technology Project-Based Learning (PBL).

The website provides a platform where users can explore available properties, property owners can add and manage their property listings, and administrators can manage users and approve property submissions.

## 🎯 Objectives
- To develop an easy-to-use real estate management platform.
- To allow users to explore available properties.
- To help property owners manage their property listings.
- To provide administrators with property management and approval facilities.
- To implement secure user authentication and database management.

## ✨ Features

### 👤 User
- User registration and login.
- Browse available properties.
- View property details.
- Send property enquiries.

### 🏠 Property Owner
- Owner dashboard.
- Add new properties.
- Manage listed properties.
- View customer enquiries.

### 🔐 Admin
- Admin dashboard.
- View property submissions.
- Approve or manage property listings.

## 📂 Project Structure

- Frontend – User interface and website pages.
- Backend – Server-side logic and API management.
- Database – Stores user and property-related information.

## ⚙️ Installation and Setup

1. Download or clone the project repository.
2. Extract the project ZIP file.
3. Open the project in Visual Studio Code.
4. Install the required Node.js dependencies.
5. Configure the MySQL database.
6. Start the backend server.
7. Open the frontend using Live Server.
